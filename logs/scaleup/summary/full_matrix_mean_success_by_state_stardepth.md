# Full Matrix: Mean Success Rate by (#States, StarDepth)

- Each regex is run 3 times.
- For each regex: `success rate = successful reruns / 3`.
- For each `(#States, StarDepth)` cell: average the success rates of the first 3 regexes from `datasets/scaleup/regex_list.json`.
- Cell format: `mean success rate% [r1, r2, r3]`, where `r1..r3` are the per-regex success rates in percent.
- Missing log files are treated as `0/3`.
