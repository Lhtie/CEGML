# Program induction benchmarks

These data files preserve the authors' public training and test examples. The adapter in `tasks/benchmarks.py` reads one task instance at a time. No benchmark outputs are generated by a language model.

| `--task_type` | `--benchmark_id` | Source | Oracle |
|---|---|---|---|
| `cryptography` | `caesar:0` through `caesar:99`, `atbash:0` through `atbash:99`, or `keyboard:0` through `keyboard:99` | [Robust Rule Induction](https://github.com/HKUST-KnowComp/Robust-Rule-Induction) | cvc5, decidable character-substitution equivalence |
| `list_functions` | `c001` through `c250`, where present in the source file | [Robust Rule Induction](https://github.com/HKUST-KnowComp/Robust-Rule-Induction), derived from Rule's list-function benchmark | cvc5 sequence theory for directly translatable functions, then cvc5 selection over a bounded concrete input pool |
| `instruction_induction` | Task stem, for example `antonyms` or `sentiment` | [Instruction Induction](https://github.com/orhonovich/instruction-induction) | A separate LLM semantic-equivalence call, with a requested counterexample |
| `scan` | `simple`, `length`, `addprim_jump`, `addprim_turn_left`, or `template_*` | [SCAN](https://github.com/brendenlake/SCAN), standard splits and full `tasks.txt` | Exhaustive enumeration of all 20,910 public commands |

The SCAN repository attributes the benchmark to Lake and Baroni (2018). The paper *Human few-shot learning of compositional instructions* studies related compositional instruction learning, but its human experiment is a distinct dataset.

## Run

```bash
python train_icl_gen.py --task_type cryptography --benchmark_id caesar:0 --mkey gpt5 --use_ce
python train_icl_gen.py --task_type list_functions --benchmark_id c170 --mkey gpt5 --use_ce
python train_icl_gen.py --task_type instruction_induction --benchmark_id antonyms --mkey gpt5 --use_ce
python train_icl_gen.py --task_type scan --benchmark_id simple --mkey gpt5 --use_ce
```

Omit `--use_ce` for the LLM baseline. `baseline.py` also forwards these four task types to that no-counterexample path:

```bash
python baseline.py --task_type list_functions --benchmark_id c170 --mkey gpt5
```

For direct input/output ICL, use `train_icl.py` with the same `--task_type` and `--benchmark_id`. Add `--use_ce` for mistake-driven counterexample selection from the benchmark's labeled training examples. See [`benchmarks/README.md`](../benchmarks/README.md) for commands.

`--rerun`, `--retries`, `--seed`, `--start_size`, `--scale_factor`, `--tot_train_size`, `--eval_size`, `--ce_epochs`, `--ce_start_size`, and `--ce_batch_size` work with these tasks. `--use_reg` adds a concision constraint to the prompt. Results are saved under `logs/opt_prompt/icl_gen_<task_type>/model=<mkey>/ce|std/reg|noreg/<benchmark_id>.json`.

With `train_icl_gen.py --use_ce`, the first epoch takes up to `--ce_start_size` published examples (default 8). Later epochs request up to `--ce_batch_size` counterexamples (default 8 for these four benchmarks; regex remains 128). The actual count may be zero. Cryptography has at most 52 distinct single-letter witnesses; List Functions and SCAN can return multiple witnesses up to the requested limit; Instruction Induction asks the LLM for up to that limit in one call. Direct `train_icl.py --use_ce` instead adds model mistakes from each scheduled batch of the published training pool, capped at `--ce_batch_size` (default 8) per epoch.

## Oracle limits

List-function equivalence for arbitrary Python is undecidable. Its cvc5 sequence query searches symbolic integer lists of length 3–8, with values 0–100, when both functions fit the supported expression subset. Otherwise it evaluates the functions on the published examples and generated lists, then uses cvc5 to select disagreements. A list-function result with no witness has `Equivalent: null`, never `true`.

Instruction Induction's LLM oracle is heuristic. It requests up to `--ce_batch_size` distinct counterexamples in one call and verifies claimed labels when an input appears in the published data. Novel-input claims and equivalence verdicts may still be wrong; the logs retain the oracle response. No exact execution accuracy is reported for that task because the benchmark has no executable reference function.

Candidate list and SCAN programs are restricted to a small Python subset and run with a per-input timeout. These limits may reject otherwise valid hypotheses.

The two SMT oracles require the `cvc5` command-line program. The project Dockerfile installs it separately from the Python bindings in `requirements.txt`.
